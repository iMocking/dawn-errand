# 曙光跑腿 · 客户端高德地图配送追踪适配说明（v1.2.0）

> 项目根：`D:\code\github\dawn-errand`；工程：`apps/client`（Android 原生 Kotlin，包名 `com.dawnerrand.client`）。
> 目标：配送进度页接入高德地图服务，客户实时追踪外卖/跑腿配送进度，替换 v1.1.0 的伪地图（`bg_map` 背景 + 固定 pin）。

---

## 1. 版本与依赖

| 项 | 值 |
|---|---|
| 高德合包 | `com.amap.api:3dmap-location-search:11.3.100_loc11.3.101_sea9.8.1`（3D 地图 V11.3.100 + 定位 V11.3.101 + 搜索 V9.8.1，官方当前最新合包） |
| 仓库 | Maven Central（官方 `maven.amap.com` 在当前网络不可达；Central 已同步该合包，Gradle 可直接解析） |
| 产物形态 | 普通 jar（37 MB，内含 `assets/map_assets` 与 `lib/{arm64-v8a,armeabi-v7a}/*.so`），**无自带 res/manifest** → 定位 SDK 的 `APSService` 需在应用 Manifest 手动声明（见 §4） |
| ABI | 仅 arm64-v8a / armeabi-v7a（高德 10.x 起不再发布 x86/x86_64 so）；x86_64 模拟器经 arm64 转译可运行，本机已实测通过 |
| APK 体积 | 约 74 MB（含地图引擎与素材） |
| 版本号 | versionCode 3 / versionName 1.2.0（v1.1.0 → v1.2.0） |

## 2. 高德 Key 配置（必需，需在开放平台申请）

1. 注册高德开放平台：<https://lbs.amap.com>
2. 控制台 → 应用管理 → 创建应用 → 添加 Key，平台类型选 **Android**；
3. 填写以下绑定信息：
   - 安全码 SHA1（调试签名，可用 `keytool` 从 `%USERPROFILE%\.android\debug.keystore` 导出）：
     `94:EF:1B:BB:5F:51:D9:1C:8E:39:EF:21:D6:F4:B6:6B:61:FA:4E:20`
   - 包名：`com.dawnerrand.client`
4. 构建时注入 Key：

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
Set-Location "D:\code\github\dawn-errand\apps\client"
.\gradlew.bat assembleDebug -PamapKey=<你的Key>
```

> 未配置 Key 的表现：地图不渲染（logcat 输出 `INVALID_USER_KEY` / `errorCode 10001` 鉴权提示），页面其余功能（状态卡、进度、骑手卡、模拟移动）全部正常。
> 生产发布：必须用**正式签名 SHA1** 重新申请 Key 并在发布构建中注入。

## 3. 工程接入清单

| 文件 | 变更 |
|---|---|
| `gradle/libs.versions.toml` | 新增 `amap = "11.3.100_loc11.3.101_sea9.8.1"` 与库坐标 |
| `app/build.gradle.kts` | `implementation(libs.amap.map.location.search)`；`-PamapKey` → `BuildConfig.AMAP_KEY` + `manifestPlaceholders["amapKey"]`；版本号升级 |
| `app/src/main/AndroidManifest.xml` | 权限：`ACCESS_WIFI_STATE` / `ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION` / `ACCESS_LOCATION_EXTRA_COMMANDS`；`<meta-data android:name="com.amap.api.v2.apikey" android:value="${amapKey}"/>`；`<service android:name="com.amap.api.location.APSService"/>` |
| `ClientApp.kt` | `initAmapPrivacy()`：`MapsInitializer.updatePrivacyShow/Agree` + `AMapLocationClient.updatePrivacyShow/Agree`（合规前置，必须早于任何 SDK 调用） |

> 隐私合规：演示环境默认按「已同意」初始化；**上线必须改为在用户主动勾选《隐私政策》后回调**（登录/注册页已有 LegalActivity 入口）。

## 4. 架构设计（MVVM 数据驱动）

数据流（单一数据源 `OrderTrackViewModel.uiState: StateFlow<OrderTrack?>`）：

```
                         OrderTrackViewModel.uiState
                        （StateFlow<OrderTrack?>）
   ┌──────────────┬───────────────┬───────────────┬──────────────┐
   ▼              ▼               ▼               ▼              ▼
状态卡          进度 4 步        骑手卡           地图            （空→提示并关闭）
标题/描述      已提交→到店     姓名/车辆/     取货点Marker
预计送达分钟    →配送中(已行驶  接单数据/      送达点Marker
剩余距离公里    x公里)→送达确认  联系/呼叫      骑手Marker+朝向
                                               路线Polyline
                                               相机跟随/我的位置
```

分层：

| 层 | 文件 | 职责 |
|---|---|---|
| 数据模型 | `data/track/TrackModels.kt` | `TrackPoint / TrackPhase / StepState / TrackStep / OrderTrack` |
| 数据源 | `data/track/TrackingRepository.kt` | `stateFor(order, progress)` 纯函数生成追踪状态；演示路线：浠水县镇中心 → 王家湾村（7 点乡道路线，Haversine 里程/航向/ETA） |
| ViewModel | `ui/screens/ordertrack/OrderTrackViewModel.kt` | 配送中订单每 2s 推进进度 0.04 模拟骑手移动；StateFlow 驱动 UI 与地图 |
| 视图 | `ui/screens/ordertrack/OrderTrackActivity.kt` | MapView 生命周期、标记/路线/相机、状态卡与骑手卡渲染 |
| 地图辅助 | `MapPins.kt` / `AmapLocationSource.kt` | 位图标记工厂（矢量图标 + 圆底绘制）、高德定位数据源 |

**后端替换点**：追踪接口就绪后仅需把 `TrackingRepository.stateFor` 换成 `GET /orders/:id/track`（或 WebSocket 推送）的解析，ViewModel 与 UI 零改动（沿用 v1.1.0 的 DemoRepository 替换约定）。

## 5. 配送进度页实现要点

- **MapView 生命周期**：与 Activity 严格绑定 `onCreate/onResume/onPause/onDestroy/onSaveInstanceState`。
- **全屏地图**：`WindowCompat.setDecorFitsSystemWindows(false)`；顶栏半透明叠加（状态栏内边距自适应）；底部骑手卡圆角叠加。
- **标记**：取货点（绿·购物袋 `#00B578`）、送达点（红·家 `#FF4D4F`）、骑手（橙·电动车 `#FF6B2C`，随航向 `rotateAngle` 旋转）。
- **路线**：白色描边（9dp）+ 主色（`#FF6B2C`，5dp）双层 Polyline。
- **相机**：首载 `newLatLngBounds` 自适应取货-送达范围；配送中 `changeLatLng` 平滑跟随骑手，用户拖动地图后停止跟随。
- **我的位置**：运行时权限（FINE/COARSE）请求，授予后开启 `isMyLocationEnabled` + 定位按钮。
- **ETA / 距离**：Haversine 计算，按骑手平均 20 km/h 估时。

## 8. 已知限制

1. 高德 Key 未配置时地图不渲染（构建注入 `-PamapKey` 后生效）。
2. 3D 地图 SDK 仅支持 arm64-v8a / armeabi-v7a；x86 设备不可用（模拟器经转译运行，性能低于真机）。
3. 骑手位置为**演示模拟**（乡道路线匀速移动）；后端追踪接口就绪后需替换数据源。
4. 隐私默认「已同意」仅适用于演示环境；上线必须接入用户确认流程后再调用合规接口。
