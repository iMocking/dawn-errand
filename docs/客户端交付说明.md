# 曙光跑腿 · 客户端（Android 原生 Kotlin）交付说明

> 版本：v1.0.0 ｜ 工程：`apps\client` ｜ 包名：`com.dawnerrand.client`
> 基准：375×812 设计稿像素级还原（渲染基准 1 design px = 1dp，模拟器 Physical 1080×2400 / wm 984×2132 / density 420）
> 说明：本工程已由 Godot 版整体重写为 Android 原生 Kotlin，旧 Godot 实现已清空（git 可恢复）。

---

## 1. 总览

本工程将原 Godot 版客户端整体重写为 **Android 原生 Kotlin**，覆盖 `design\client` 全部 15 个业务屏 + Splash + 登录，并实现完整业务逻辑。设计令牌与 driver（骑手端）、store（商家端）同源（Design.kt 统一 PRIMARY `#FF6B2C` 等），保证三端视觉一致性。

**15 屏清单**：Splash / Login / Home / Errand（跑腿）/ Orders（我的订单）/ Search / MerchantDetail / OrderConfirm / PaySuccess / OrderTrack / Review / Address / AddressEdit / Coupons / Profile。

## 2. 工程结构

```
apps\client
├── settings.gradle.kts / build.gradle.kts / gradle.properties / local.properties
├── gradlew(.bat) + gradle\wrapper（Gradle 9.8.2）
└── app
    ├── build.gradle.kts        # namespace/applicationId=com.dawnerrand.client、API_BASE_URL=http://10.0.2.2:8080
    └── src\main
        ├── AndroidManifest.xml # Splash(launcher) + Main + 12 个业务子 Activity（exported=false）
        ├── res\values          # colors / themes(Theme.DawnClient) / strings
        ├── res\drawable        # 115 个资源：63 个继承 + client 专属 17+ 图标与背景（pathData 与设计稿 SVG 逐字一致）
        └── java\com\dawnerrand\client
            ├── data\DemoRepository.kt        # 全部 demo 数据 + 会话 + 购物车 + 订单 + 地址 + 优惠券
            ├── ui\theme\Design.kt            # 设计令牌（与 driver 同源）
            ├── ui\util\Ext.kt                # dp/sp/toast/padTopWithStatusBar/padBottomWithNavBar
            ├── ui\components\TabBarView.kt   # 四 tab：首页/跑腿/订单/我的
            └── ui\screens\<page>\<Activity/Fragment>.kt + layout\*.xml（15 屏）
```

## 4. 页面与业务逻辑

### 4.1 Splash
紫→橙 90° 渐变底 + 6 颗白星 + 居中骑行 logo + 「曙光跑腿 / DAWN ERRAND / 乡镇跑腿·随叫随到」+ v1.0.0，1.4s 后按会话状态跳 Login 或 Main。

### 4.2 Login（登录）
橙渐变头（欢迎登录 + 标语）+ 白色 16dp 圆角表单卡（+86 竖分割线 / 手机号 / 验证码 / 获取验证码 60s 倒计时 / 登录·注册 24dp 渐变钮 / 协议圆勾默认 ✓ 可切换）+「其他登录方式」分隔线 + 微信/支付宝白圆钮（点击提示建设中）。
**演示模式**：校验 11 位手机号 + 任意 6 位验证码，成功写入 `SharedPreferences("client_session")`（key: token/phone），token 为 `demo-token-<millis>`。
> 注：后端暂无 C 端业务接口，登录为演示模式；若后续提供真实接口，将 LoginActivity 的校验替换为对应 API 即可（`API_BASE_URL` 已预置）。

### 4.3 Home（首页）
渐变头（「中午好，王建国 👋」/ 定位「王家湾村三组·红砖大铁门」/ 白搜索条 → Search）+ 双场景卡（点个饭 → m1 商家、跑个腿 → Errand）+「村里人都在点」推荐横滑 140dp 卡（88dp 色块图 + **短名** + 评分·分钟）+「离你最近」4 张卡片（渐变 banner / 名称 / 距离 / 评分·月售 / 标签），列表项 marginBottom 10dp。

### 4.4 Errand（跑腿代办）
44dp 白导航「跑腿代办」+ 4 类型 tab（帮我买 / 帮我送 / 帮我取 / 帮我办，选中橙字+BOLD）+ 取/收地址卡（绿起点·红终点圆点 + 三行地址 + 灰圆交换钮）+「买什么」描述框（placeholder 即设计稿文案 + 3 橙色 tag）+ 费用预估浅黄卡（跑腿费 5.2km ¥8.0 / 商品垫付约 ¥120 / 需预付 ¥8.0）+ 底部白条「跑腿费 ¥8.0」+ 渐变「立即下单」→ PaySuccess（amount 8.0 / type 跑腿 / order_no DD…）。描述为空时自动使用默认描述「代买代送（按清单采购）」放行（演示模式）。

### 4.5 Orders（我的订单）
4 筛选 Tab（进行中 / 已完成 / 已取消 / 退款售后），选中 BOLD + 橙色下划线 `bg_tab_indicator`；订单卡（店名 / 状态色：进行中橙、其余灰 / 56dp 彩底图标 / 明细 / 时间 / 实付红色大字 + 操作按钮：查看配送 → OrderTrack、评价 → Review、其余 toast）；空 tab 显示「暂无相关订单」。

### 4.6 Search（搜索）
返回 + 圆角搜索框（放大镜，hint「搜索商家、商品」+ 橙色搜索按钮）+「热门搜索」chips（农家小炒肉 / 王家湾超市 / 红富士苹果 / 李记卤味）+「最近搜过」列表（带 ✕ 可删）；搜索按商家名包含匹配跳商家详情，无结果 toast。

### 4.7 MerchantDetail（商家详情）
入口：首页「点个饭」场景或附近商家卡。hero 160dp 双圆角渐变 + 半透明角标「🔥 本周热销 · 已售326份」+ 上浮返回/更多圆钮；信息卡负 margin 叠盖（店名 / ⭐4.8分 / 2.1km / 约25分钟 / 满25免配送 + 新用户立减3元 tag）；5 分类 chip（🔥 热销爆款 active 橙底白字）；菜品卡（56dp 色块图 / 名称 / 描述含月售 / ¥红字 / 橙色加购按钮）；深色购物车栏（#1D2129 64dp：橙圆购物车 + 红角标件数 + 合计 + 另需配送费 ¥3 + 去结算渐变钮）；cart 空点结算 toast；下单走 OrderConfirm。

### 4.8 OrderConfirm（确认订单）
地址卡（浅橙圆 pin + 王建国 138****8888 + 王家湾村三组26号…）+ 商品卡（店名 + 逐行 菜品×N / 商品小计 / 配送费 ¥3.0 / 打包费 ¥1.5 / 新用户立减 -¥3.0 橙）+ 送达时间 / 配送方式 / 订单备注 + 支付方式（微信支付 + ic_check）/ 优惠券（已减 ¥3）+ footer「合计 ¥XX.X」+ 提交订单。
**下单公式**：合计 = 菜品小计 + 配送费 3.0 + 打包费 1.5 − 新用户立减 3.0。提交后按购物车动态生成新 Order（进行中）并清空购物车 → PaySuccess。

### 4.9 PaySuccess（支付成功）
72dp 绿圆大勾 + 支付成功 / 金额红 + 信息卡（订单类型 / 订单编号 / 送达地址）+ 返回首页（轮廓）/ 查看配送（橙渐变）→ OrderTrack。

### 4.10 OrderTrack（配送进度）
地图底 #E8ECEB + 半透明黑导航「配送进度」+ 中部垂直橙色虚线路线（绿标签取货点 / 橙骑手 pin 44dp / 红标签送达点）+ 白状态卡（骑手正在取货 · 预计 12:45 送达 · 距您 1.2km + 桔电话钮）+ 两段进度条（商家接单/骑手取货绿、送达灰 + 三 label）+ 骑手卡（头像 / 李师傅·鄂J 8D621 / ⭐4.9 · 已接1286单 + 橙「呼叫」）。

### 4.11 Review（评价）
5 颗 ★（30f，选中 #FFB020 实星，可重选）+「非常满意」+ 6 个快捷标签多选（味道好/分量足/送得快/包装好/服务热情/食材新鲜）+ 100dp 文本域 + 底部渐变提交（空 → toast，成功 → toast + 关闭）。

### 4.12 Address / AddressEdit（收货地址）
地址列表 3 卡（姓名+电话 / 两行详细地址 / 标签：默认·家 橙底、医院/学校 灰底 / 右侧 ✎ 铅笔 → Edit）；底部渐变「新增收货地址」。编辑页：白卡片三行（联系人 / 手机号 / 详细地址 带分割线）+「地址标签」chips（家/公司/学校/其他 单选切换）+ 渐变保存（校验姓名 / 11 位手机 / 明细后 toast 保存成功）。

### 4.13 Coupons（优惠券）
券卡：左 96dp 橙渐变「¥5 / 满20可用」或灰渐变「已过期 ¥8」，右白区标题 / 描述 / 有效期 /「去使用」（橙描边圆角）或「已过期」灰字。数据：¥5 满20 新用户立减券（至 2026-10-29）、¥3 无门槛 骑手好评奖励券（至 2026-10-25）、¥8 满30 周末专享券（已过期 2026-10-20）。

### 4.14 Profile（我的）
渐变头（头像 + 王建国 138****8888·王家湾村）+ 资产卡重叠 -16dp（优惠券 2 / ¥15 / 128 / ★5）+ 我的订单卡（全部订单 → Orders + 待支付/待接单/配送中/待评价 四 icon → Orders）+ 菜单①（收货地址 3个 → Address、优惠券 2张可用 → Coupons、商家入驻 / 成为骑手 → toast）+ 菜单②（联系客服 / 帮助中心 / 设置 → toast 占位）。

## 7. 复用与扩展

- 新增程序化 UI 屏：注意 `apply{}` 内调用 dp()/sp()/toast() 会被 View receiver 遮蔽，必须使用 `ctx.dp()` 前缀（模板见工作区 `fix_ctx.py`）。
- 三端一致性：Design.kt / Ext.kt / SwitchView.kt 与 driver 同源；图标 pathData 与设计稿 SVG 逐字一致。
- 切真实后端：替换 DemoRepository 为 Retrofit/OkHttp 调用，`API_BASE_URL=http://10.0.2.2:8080` 已配置。
