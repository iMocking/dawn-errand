# 曙光跑腿 · 官网（web）UI 设计 Brief

## 主题与核心对象
- 主题：为乡镇跑腿/外卖 SaaS 平台「曙光跑腿 · Dawn Errand」设计对外官网（官网/落地页）。
- 核心对象：项目对外门户与下载中心——产品介绍、能力全景、适用场景、核心功能、多端下载、FAQ、商务合作、版本动态。
- 商品/实体：无实体商品，SaaS 平台产品；对外官网承担品牌展示与转化（下载 App、联系商务）。

## 受众与使用场景
- 潜在商家/店主、跑腿骑手、普通用户（下单者）、城市代理/商务合作方，以及投资人与平台运营方。
- 场景：PC 桌面浏览与手机移动端浏览；访客了解产品能力、判断适用场景、下载多端 App、咨询商务合作。

## 设计系统继承（与三端/后台一致）
- 主色：曙光橙 #FF6B2C；渐变主视觉 linear-gradient(135deg,#FF8A3D,#FF6B2C)。
- 浅橙底 #FFF3E8；页面背景 #F5F6F8；文字主色 #1D2129、次 #4E5969、弱 #86909C。
- 语义色：红 #FF4D4F（警示/待办）、蓝 #2B7FFF（信息）、绿 #00B578（成功/在线）、黄 #D48806（警告/审核中）、紫 #722ED1。
- 图标：全部使用内嵌 SVG 线框图标（2px 描边、圆角端点、stroke 风格），禁止 emoji。
- 字体：系统字体栈 -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif。
- 历史产物：design/admin（后台）、design/client（用户端）、design/store（商家端）、design/driver（骑手端）；官网输出至 design/web。

## 生产路线与交付
- 生产路线：pure-coding / 响应式 HTML（全部 HTML/CSS/内嵌 SVG 表达，无生图素材）。
- 页面画布：响应式布局，桌面 1440 基准、移动 390 基准；一套官网多页面，共享顶部导航与页脚。
- 页面清单（4 页）：
  1. index.html —— 官网首页（导航 + Hero + 数据信任条 + 能力全景 + 适用场景 + 核心功能 + 多端矩阵 + 版本动态 + FAQ 摘要 + 合作 CTA + 页脚）
  2. download.html —— 多端下载中心（用户端 / 商家端 / 骑手端 APK 下载、管理后台入口、扫码直达）
  3. faq.html —— 常见问题（入驻、配送、结算、售后、安全）
  4. contact.html —— 商务合作（合作模式、联系方式、合作流程）

## 内容事实来源
- 产品能力、技术栈、多端矩阵、路线图均来自项目 README.md 与后端交付报告（可追溯）。
- 产品矩阵：官网(Web Vue3)、管理后台(Web Vue3+Tailwind+Vite)、用户端(Android Kotlin·MVVM)、商家端(Android Kotlin)、骑手端(Android Kotlin)。
- 技术栈：Go 1.27 · Gin · ent（ORM）· Casbin（RBAC 七角色）· PostgreSQL 16 · Redis 7 · JWT 会话轮换 · AES-GCM · 邮箱/短信验证码 · Prometheus。
- 适用场景：社区跑腿、同城配送、餐饮外卖。
- 核心链路：多端 → Go 后端(Gin :8080) → PostgreSQL/Redis。
- 下载中心文案：Android 用户端 / 商家端 / 骑手端 APK；管理后台入口。
- 商务合作：城市合伙人、商家入驻、骑手招募、渠道合作（联系方式为占位，标注“以官网/邮件联系为准”）。

## 视觉主张与阅读结构
- 第一焦点：Hero 主视觉——品牌渐变 + 大标题「让每个乡镇的订单都被认真送达」+ 双 CTA（下载 App / 商务合作），配多端产品矩阵插画式图标组。
- 第一焦点不与其他节点竞争；数据信任条（覆盖乡镇、服务用户、合作骑手）用橙色主数据 + 语义色辅助。
- 能力全景：9 宫格能力卡（下单派单、实时配送、订单跟踪、财务结算、多角色权限、区域费率、商家管理、骑手管理、数据看板）。
- 适用场景：三张场景卡（社区跑腿、同城配送、餐饮外卖），浅橙底 + 线框图标。
- 核心功能：列表式功能条目 + 图标，突出「下单、派单、配送跟踪、财务结算、多角色权限」。
- 多端矩阵：用户端 / 商家端 / 骑手端 / 管理后台四端卡片。
- FAQ：两栏手风琴式折叠（原生 <details>）。
- 页脚：产品矩阵、帮助支持、商务合作、联系方式（占位）四列 + 版权行。

## 响应式策略（PC + 移动端）
- 断点：≥1024px 桌面多列；768–1023px 平板两列；<768px 移动端单列，导航折叠为抽屉菜单。
- 移动端 Hero 文字与按钮纵向堆叠，卡片栅格 1 列，内边距收窄（20px）。
- 桌面导航：Logo + 导航链接 + 下载按钮；移动端：汉堡按钮展开菜单面板。
- 触控热区 ≥44px；正文 ≥14px；输入框 ≥16px。

## 可编辑范围
- 全部标题、正文、数据、标签、按钮为真实 DOM 文字；图标全部内嵌 SVG 线框风格，可编辑。
- 交互：导航链接、下载按钮、FAQ 折叠、移动菜单为真实交互（点击/toast），不使用僵尸按钮。

## 验收重点
- 与三端品牌一致（曙光橙主色、渐变、SVG 线框图标、字体栈）。
- PC（1440）与移动（390）双视口均完整可读，无横向溢出、无遮挡、无缺字。
- 数据真实可信：来自 README/交付报告；占位联系方式明确标注。
- 每页独立可开，导航可跳转，FAQ 可展开，移动端菜单可用。
- shot.py 双视口自检通过。
