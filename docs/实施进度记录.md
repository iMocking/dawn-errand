### 目标
落地"系统内置 System 身份"设计（见 `docs/系统身份设计分析.md`），并纳入初次启动初始化流程。

### 完成事项
1. **身份模型**（`internal/domain/identity/identity.go`）
   - 新增角色 `RoleSystem = "system"`（显示名"系统服务"），加入 `AllRoles`；
   - 新增 `SystemIdentities` 清单（4 个系统级身份，固定邮箱）：
     - `mailer@system.shuguang` 邮件服务系统
     - `sms@system.shuguang` 短信服务系统
     - `inmail@system.shuguang` 站内信通知服务系统
     - `system@shuguang.local` 基础系统服务
2. **初始化流程**（`internal/application/system/service.go`）
   - 新增 `EnsureSystemUsers(ctx)`：事务内按邮箱幂等创建；已存在 system 身份跳过；邮箱被真实用户占用则跳过（**绝不覆盖人工账号**）；不创建登录凭证（禁登录）；
   - `Bootstrap`（`POST /api/system/bootstrap` 初次启动初始化）在写入默认策略与默认配置之后、`MarkInitialized` 之前调用，失败则初始化不完成。
3. **种子兜底**（`cmd/seed/main.go`）：bootstrap 后同样执行 `EnsureSystemUsers`，保证直接 seed 的开发环境也有系统身份（输出"系统身份已就绪: 4 个"）。
4. **权限策略**（`internal/infrastructure/casbin/casbin.go`）：`DefaultPolicies` 明确 system 角色**默认不授任何业务权限**（仅身份/审计主体；内部调用入口上线时按最小权限显式授予，禁止 `*`）。
5. **集成测试**（`internal/integration/api_test.go`）
   - 新增 `TestSystemIdentities`：4 个系统身份在用户列表可见（按名称断言）；`mailer@system.shuguang` 登录返回 1002（禁登录）；
   - 修复发件箱取令牌的不稳定性：`mailToken` 增加主题关键词过滤（验证/重置邮件同一秒 created_at 时排序不稳定，曾导致取错邮件→reset 1006）。
