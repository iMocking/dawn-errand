## 3. 双登录实现

### 3.1 UI（activity_login.xml + LoginActivity.kt）

白卡片顶部「邮箱登录 / 手机号登录」双 Tab（**邮箱登录默认选中优先**，短信验证码登录排后）：选中态主色加粗 + 24×3dp 橙色下划线指示条（`bg_tab_indicator.xml`），未选中灰色。Tab 切换联动两块输入区（`layoutEmail` / `layoutPhone`）显隐。

### 3.2 邮箱登录（真实接口）

`POST {API_BASE_URL}/api/auth/login`，请求体 `{"account":"<邮箱>","password":"<密码>"}`（**字段名必须是 `account`，不是 `email`**；account 支持邮箱或手机号）。

- 成功：`code=0`，`body={token, refresh_token, user{id,name,avatar,role}, permissions}`；token 写入 `SharedPreferences("driver_session")` 与 `ApiClient.accessToken`，进入主界面。
- 失败：透传后端 `message`（如 401 `账号或密码错误`、403 未验证邮箱提示）以 Toast 展示，不进入主界面。
- 网络异常：Toast「无法连接服务器，请检查网络后重试」。
- 网络调用在 `Dispatchers.IO` 执行（`viewModelScope.launch` 默认 Main，同步请求必须在 IO 线程，否则 `NetworkOnMainThreadException`）。

### 3.3 手机号登录（演示模式）

当前 8080 运行的旧预编译后端缺 `/api/auth/sms/send`、`/api/auth/sms/login`（404/code 1401）。前端在请求失败后自动进入**演示模式**：Toast「后端未提供验证码接口，已进入演示模式：任意6位验证码可登录」，任意 6 位验证码放行。

- 演示账号：手机号 `13966668888` + 验证码 `123456`

### 卡包管理（新增功能）

- **入口**：我的页「卡包管理」（原资质认证行，icon 换为银行卡 `ic_card`，右侧动态显示「银行卡 N 张」，返回本页时 onResume 自动刷新）。

- **银行卡（多卡）**：支持绑定多张、可增删：
  - 添加：橙色「+ 添加银行卡」按钮 → **弹窗输入样式对齐登录页**（白卡片 + label + 透明底下划线输入行 + 分割线，四个字段：持卡人 / 卡号 / 开户银行 / **有效期 MM/YY**）→ 校验（姓名非空、卡号 ≥12 位纯数字、有效期 `MM/YY` 格式）→ 保存；**校验失败对话框保持打开**（避免输入丢失）。

  - 卡面：橙色渐变卡（16dp 圆角），银行名 + 掩码卡号 + 底部两列（持卡人 / **有效期**）。

## 8. 已知限制与偏差

1. **业务数据为演示数据**：后端 `/api/orders/pool` 等业务接口需登录态或不存在（404），骑手端业务数据由 `DriverRepository` 注入演示数据（与 client 端约定一致）。邮箱登录的**登录态为真实**（真实 token），业务数据仍走演示仓库。
2. **手机号验证码为演示模式**：需后端补充 `/api/auth/sms/*` 后即可切为真实链路（见 `docs/客户端交付说明.md` §auth 契约）。
3. **注册入口**：登录页无独立注册表单，注册走接口 `POST /api/auth/register`（footer「免费注册加盟」为 Toast 引导）。
4. **设计偏差记录**：① profile 菜单补「每日签到」行（原稿无此入口，为保证签到页可达，代码注释已说明）；②「已确认送达」「提现」「联系顾客」等为 Toast 交互；③ 渲染基准为 420dpi 下 984px=375dp。
5. **演示账号固定数据**：工作台/接单等数据与登录账号无关（演示仓库）。
6. **卡包为本地存储**：银行卡绑定/解绑存于本机 `SharedPreferences`，后端卡包接口就绪后可替换 `CardWalletRepository` 为 ApiClient 调用（视图层零改动）。

| login | `POST /api/auth/login` | `{account, password}` | account 支持邮箱/手机号；成功 body `{token, refresh_token, user, permissions}`；未验证邮箱 403 |
