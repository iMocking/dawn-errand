## 1. 变更摘要与影响范围

### 1.1 整体交付
- DDD 四层架构完成：`domain`（纯 Go 领域模型/端口）、`application`（用例编排/事务/权限）、`infrastructure`（ent 持久化/Casbin/Redis/令牌/邮件/存储/指标）、`interfaces`（Gin 路由/中间件/DTO）。
- 数据模型：ent 17 张表（users/credentials/email_verification_tokens/password_reset_tokens/regions/merchants/riders/user_profiles/orders/withdrawals/settlements/complaints/fee_rules/announcements/system_settings/casbin_rules/mail_outboxes），全部 ULID 主键、UTC int64 时间戳。
- 权限：Casbin RBAC，7 种角色 `user / super_admin / cs_manager / cs_agent / region_station / merchant / driver`；中间件 `RequirePerm(obj, act)` + 仓储层 `Scope` 强制数据隔离（Global / RegionID / MerchantID / RiderID / UserID）。
- 身份闭环：注册（邮件验证 1003 门禁）→ 验证（GET /auth/email/verify）→ 登录 → 刷新（refresh_token 轮换）→ 登出（会话版本升级，全端失效）→ 忘记/重置 → 改密。
- 初始化：`POST /api/system/bootstrap` 一次性初始化令牌（幂等，已初始化返回 1102）。
- 指标：`/metrics`（Prometheus），中间件自动统计。

## 4. 权限策略与审计变更
- 角色：user/super_admin/cs_manager/cs_agent/region_station/merchant/driver；Casbin 模型 p/g 段，策略存 `casbin_rules`。
- 数据隔离：Scope 派生（平台角色 Global、region_station→RegionID、merchant→MerchantID、driver→RiderID、user→UserID）；仓储层 `scopeOrder/scopeMerchant/scopeRider/scopeUser` 强制过滤；application 层对象级二次校验（tenantDenied 1509 类错误码）。
- 审计：`audit_logs` 记录敏感操作（登录/注册/重置/改密/封禁/提现审核等），含 user_id/action/object/result/request_id/ip。
- 会话：access JWT 携带 session_version，凭证版本被提升（改密/重置/登出/封禁）后旧令牌即刻 1006 失效。
