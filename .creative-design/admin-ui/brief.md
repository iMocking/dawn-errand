# 曙光跑腿 · 后台管理端 UI 设计 Brief

## 主题与核心对象
- 主题：为乡镇跑腿/外卖 SaaS 平台「曙光跑腿」设计配套的后台管理端（admin）Web UI。
- 核心对象：平台运营后台管理系统，供平台管理员管理全平台业务。
- 商品/实体：无实体商品，后台管理界面；管理对象为订单、商家、骑手、用户、财务、区域与系统设置。

## 受众与使用场景
- 平台运营/客服/财务/区域管理员，在桌面浏览器使用。
- 管理任务：查看经营总览、处理订单异常、审核入驻商家与骑手、管理用户、处理提现结算、配置区域费率与公告。

## 设计系统继承（与三端一致）
- 主色：曙光橙 #FF6B2C；渐变主视觉 linear-gradient(135deg,#FF8A3D,#FF6B2C)。
- 浅橙底 #FFF3E8；页面背景 #F5F6F8；文字主色 #1D2129、次 #4E5969、弱 #86909C。
- 语义色：红 #FF4D4F（警示/待办）、蓝 #2B7FFF（信息）、绿 #00B578（成功/在线）、黄 #D48806（警告/审核中）、紫 #722ED1。
- 图标：全部使用内嵌 SVG 线框图标（2px 描边、圆角端点、stroke 风格），禁止 emoji。
- 字体：系统字体栈 PingFang SC / Microsoft YaHei。
- 三端历史产物：design/client（用户端）、design/store（商家端）、design/driver（骑手端），后台管理端输出至 design/admin。

## 生产路线与交付
- 生产路线：pure-coding（全部 HTML/CSS/内嵌 SVG 表达，无生图素材）。
- 页面画布：桌面 Web 后台，统一 1440×900 固定画布。
- 页面清单（11 页）：
  1. login.html —— 后台登录（账号密码 + 验证码）
  2. dashboard.html —— 数据总览（核心指标卡 + 订单趋势折线图 + 业务类型分布 + 实时订单流 + 待办事项）
  3. orders.html —— 订单管理（筛选 + 表格 + 分页 + 状态标签）
  4. order-detail.html —— 订单详情（状态时间线 + 订单信息 + 配送链路 + 费用明细）
  5. merchants.html —— 商家管理（列表 + 审核状态 + 操作）
  6. merchant-audit.html —— 商家入驻审核（审核队列 + 资质预览 + 通过/驳回）
  7. riders.html —— 骑手管理（列表 + 在线状态 + 操作）
  8. users.html —— 用户管理（列表 + 状态）
  9. finance.html —— 财务结算（提现申请审核 + 结算流水）
  10. complaints.html —— 投诉售后（工单列表 + 处理）
  11. settings.html —— 系统设置（区域管理 + 配送费率 + 公告管理）
  12. index.html —— 总览（iframe 并排预览全部页面）

## 页面通用布局（后台框架）
- 左侧固定侧边栏（宽 224px，深色或白色？）：采用品牌浅色方案——白色侧边栏 + 曙光橙选中态，避免与三端风格割裂；顶部 Logo 区（曙光跑腿 · 管理端），导航分组。
- 顶部顶栏（高 56px）：面包屑/页面标题、搜索框、消息铃铛（带角标）、管理员头像与姓名。
- 内容区背景 #F5F6F8，卡片白色圆角 12px，细边框 #E5E6EB，轻阴影。

## 视觉主张与阅读结构
- 第一焦点：数据总览页的核心指标与趋势，用橙色主数据 + 语义色辅助。
- 表格：表头 #F7F8FA 底、行高 56px、状态标签圆角 4px、操作链接橙色。
- 数据卡：图标色块（浅色底 + 语义色线框图标）+ 数值 + 环比小标。
- 布局节奏：卡片间距 16px，内容区 padding 20px 24px。

## 可编辑范围
- 全部标题、正文、数据、标签、按钮为真实 DOM 文字；图表使用内嵌 SVG（数值由真实文本节点承载）。
- 图标全部内嵌 SVG 线框风格，可编辑。

## 验收重点
- 与三端品牌一致（曙光橙主色、SVG 线框图标、字体栈）。
- 桌面后台 1440×900 布局完整，无溢出、无遮挡、无滚动缺失。
- 表格对齐、状态色语义正确、选中态清晰、hover 态存在。
- 数据真实可信：乡镇场景示例数据（如王家湾村、供销社超市、镇邮政所等），金额/订单数与列表一致。
- 各页面独立可开，index.html 总览并排预览。
